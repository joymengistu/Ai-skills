# Creative work

Start with audience, emotion, purpose, constraints, references, and what must feel original. Explore several directions, then select one using explicit criteria. Fuse distant ideas only when the synthesis remains coherent and useful.

Use novelty with discipline: invent terminology sparingly, explain it by context, and avoid empty complexity. Check cultural, copyright, safety, and attribution concerns. For user-facing work, test whether the piece communicates quickly, creates the intended feeling, and respects attention.

Deliver both the artifact and a compact rationale so the user can revise direction without restarting.
