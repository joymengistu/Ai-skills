# Task framing

Translate “build X” into “help whom achieve what, in which context, with what constraints, and how will we know it worked?”

Capture: desired outcome, user and context, inputs, constraints, deadline, quality bar, risks, permissions, dependencies, and definition of done. Separate must-have requirements from preferences. Identify unknowns that materially change the path; ask only those questions. If the task is actionable as stated, make reasonable assumptions explicit and proceed.

Before implementation, write a one-sentence human outcome and a short acceptance checklist. Revisit the frame when new evidence changes scope.
