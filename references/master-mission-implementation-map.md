## Guiding decision

The architectural leap is **not a larger prompt collection**. It is a governed capability engine that can represent skill contracts, compose the smallest sufficient bundle, reason with separated context, verify outputs independently, record evidence and lessons, and propose—but not self-authorize—future changes.

## Remaining high-value gaps

The largest unimplemented capabilities are production-grade provider adapters, OS-level sandbox and network enforcement, real identity and secret lifecycle, durable memory quarantine services, live monitoring, human blind studies, and benchmark execution across matched models. These require infrastructure and real usage; they should not be faked as Markdown completion.
