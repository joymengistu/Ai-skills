# User contribution adapter: Joy

Source repository: [joymengistu/Joy](https://github.com/joymengistu/Joy)

Joy is a Vercel-inspired dashboard prototype. It contributes human-facing patterns rather than AI reasoning: semantic structure, responsive layout, real-time search/filtering, tab navigation, clear project cards, modal flows, design tokens, and restrained visual hierarchy.

Use these patterns in `skills/interaction-design/SKILL.md` and `skills/human-satisfaction/SKILL.md` to make AI systems easier to scan and control. Do not copy visual decoration unless it improves comprehension, navigation, feedback, or emotion. The repository is a design reference, not an AI capability module.
