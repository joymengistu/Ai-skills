# Execution loop

Use this loop for every non-trivial task.

## 1. Frame
State the desired outcome, stakeholders, constraints, definition of done, and any ambiguity. Convert feature language into a human result.

## 2. Route
Choose a deterministic workflow when the path is known. Choose a bounded agent loop when the path is uncertain and environmental feedback is valuable. Load only relevant skills.

## 3. Plan
Make a short plan with checkpoints, stopping conditions, dependencies, and approval boundaries. Prefer reversible steps first.

## 4. Acquire
Gather high-signal context. Inspect before editing. Use authoritative sources for factual claims. Do not ingest everything by default.

## 5. Act
Take one meaningful step at a time. Use tools with explicit intent, scoped permissions, and expected evidence. Keep an action ledger.

## 6. Ground
After each tool call or execution, compare the result with the plan. Update beliefs from observed evidence, not from wishful completion.

## 7. Verify
Test the artifact or claim. Check correctness, completeness, safety, user requirements, and reversibility. Run a second independent check for high-impact work.

## 8. Check in
Pause for user input when the action is consequential, ambiguous, blocked, or likely to surprise the user. Never convert a proposal into an external action without the required approval.

## 9. Close
Report what was done, what evidence supports it, what remains uncertain, and the most useful next step. Invite correction without making the user restart the work.
